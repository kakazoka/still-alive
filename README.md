Still Alive
============

Still alive is a 2D top-down shoot 'em up with roguelite elements and persistent progression. Kill zombies, collect gun parts and unlock new guns to survive longer.

![Still Alive Banner](https://i.ibb.co/zVMXbxth/lg-Re8z4-1.png)

Use W, A, S and D to move and left mouse button to shoot.
